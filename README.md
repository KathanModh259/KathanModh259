# Hi, I'm Kathan 👋

Final-year Computer Science & Engineering student at CHARUSAT (graduating May 2027) and a software development consultant at Altum Labs. I like finding out **how systems work internally** — and why they fail — then building things that make them more reliable.

- 🐍 **Python** is my primary language; I build concurrent tooling in **Go**
- 🐧 Comfortable on **Linux**, with containers, CI/CD and debugging down to the request level
- 📦 I **maintain an open-source package on PyPI** used by people outside my team
- 🔍 Currently learning my way around the **Podman / containers** ecosystem

## Projects

| Project | What it is | Stack |
|---|---|---|
| [**pulsecheck**](https://github.com/KathanModh259/pulsecheck) | Concurrent HTTP health checker: bounded worker pool, context timeouts, cancellation-aware backoff, CI-friendly exit codes. Race-detector tested, runs as a non-root container. | Go |
| [**LatentGate**](https://pypi.org/project/latent-gate/) | Open-source package (with an MCP server) that cuts LLM API cost by ~80%. I own the API, tests, docs and releases. | Python, FastAPI |
| [**DevMirror**](https://devvmirror.vercel.app/) | Real-time collaborative code editor for 10+ languages, synced over WebSockets with Redis pub/sub. | Node.js, React, Redis |

## What I care about in code

- **Tests before trust.** Nothing ships without tests — 125 automated tests guard the production system I work on.
- **Reliability you can measure.** I once took a client service from 94% to 99% uptime by tracing the failures to their root cause instead of patching symptoms.
- **Docs are part of the code.** If someone can't use it from the README, it isn't finished.
